About Project

Built for Compiler Design Evaluation

VoxCode AI Compiler is designed as an academic demonstration of how modern AI can emulate phases of a compiler-inspired workflow: taking source input, interpreting intent, generating code, executing it, and presenting output or errors through clear runtime feedback.

Voice to Code

Capture spoken programming instructions through browser speech recognition and convert them into editable source prompts.

AI Code Generation

Use the local Ollama API with the deepseek-coder model to generate clean source code in Python, C++, or Java.

Compiler-Like Execution

Run Python code through the backend, then present runtime output, diagnostics, and execution status in dedicated consoles.

Key Features

Visible AI Innovation Features

Voice Input

Starts browser speech recognition and fills the instruction box directly.

Refine Code

Improves existing code using short commands like add comments or optimize it.

Explain Code

Generates simple step-by-step explanations for beginners and project evaluators.

Error Feedback

Highlights syntax errors, runtime errors, timeouts, and unsupported execution modes cleanly.

How It Works

Project Workflow

1. Speak or type programming instruction
2. Convert voice to text
3. Send intent to FastAPI backend
4. Generate or refine code using Ollama
5. Display code in editor
6. Run Python code and capture output or errors

Source Input Processing

The user instruction acts like a high-level source program entering the system.

Parsing User Intent

Speech recognition and prompt engineering work together to interpret what program the user wants.

Intermediate AI Code Generation

The AI model converts the parsed intent into structured source code that can be executed.

Execution and Error Handling

The backend runs code, captures output, reports syntax or runtime errors, and displays compiler-style feedback.
